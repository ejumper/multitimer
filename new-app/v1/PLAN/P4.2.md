# P4.2 — Group interactions (degradable part)

**Goal:** Grouping: create (≥1 consecutive selected), repeat modal (auto-on-create, re-open via bracket bar), ungroup (outermost only), single-interval groups. The fiddliest UI part — isolated so it can degrade cleanly.

**Prereqs:** P4.1 green.

**Read-first:** UI-REFERENCE items 8–10 (repeat stepper popover, bracket selection, nesting) + view the images: "../../../multitimer-spec/REFERENCE-IMAGES/Screenshot 2026-10-27 at 8.58.11 PM.png", ../../../multitimer-spec/REFERENCE-IMAGES/IMG_6230.PNG; FINAL-APP-OUTLINE.md §1 (group definition); CONVENTIONS §5 (fallback discipline).

## Tasks

1. **Group enablement:** group icon disabled unless selection is ≥1 interval AND contiguous in the tree (any mix of chips/groups). Grouping wraps the selection in a new group (repeat 1).
2. **Repeat modal:** on group creation, pop the stepper modal (UI-REFERENCE item 8: `− N +` / OK). Re-open by selecting the group's vertical bracket bar. N ≥ 1 integer; N = total passes. Committing updates bracket count + any parent totals shown.
3. **Ungroup:** icon enabled only when a group bracket is selected; only the outermost group of a selection is selectable/ungrouped (inner groups reachable only after ungrouping outer — mirror MultiTimer).
4. **Single-interval groups:** grouping a single selected interval is legal (repeat-one-thing; replaces MultiTimer's per-interval Repeat row).
5. **Selection model:** tapping chip toggles its selection; tapping a bracket selects the whole group (chips inside show grouped-selection state); mixed chip+group selection allowed for duplicate/delete (P4.1 ops) but grouping requires contiguity as above.

## Degrade path (only if blocked per CONVENTIONS §5)

Ship "flat groups only" (no nesting UI: nesting still renders if data has it; creation limited to top level). Engine keeps full nesting regardless. A degrade is a *documented decision in the report*, never a silent one.

- Outermost-only ungroup through 2-level nesting.
- Bracket-bar select → modal re-open; OK/± behavior.
