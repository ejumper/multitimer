## Tasks

1. **Dial widget:** outer thin ring (timer color), tick-mark ring (elapsed portion dimmed, remaining accent), center readout:
   - `notStarted`: total planned, big MonoLisa, `NNᴴ NNᴹ` style with small seconds (mirror screenshot 6214).
   - `running`: small top line = **total board remaining** (`6h 44m` style); big line = current interval remaining (`14:59`); divider; small line = `N. label`; `PAUSED` chip appended to big line when paused.
   - Below dial: caption `≫ <next N. label - duration>` (hidden when none).
2. **Interaction:** left-click dial or Space = context action: notStarted→start; running→pause; paused→resume; awaitingAdvance→advance (same as ">"). Keyboard focus + Space handled globally on this screen.
3. **Right-click** opens timer editor — stub: route exists, editor built in P4.1; for now an empty "editor placeholder" screen.
4. Replace P2.1's debug screen as home. Ticker-driven rebuilds; no business logic in widgets (read snapshot, dispatch intents only).
