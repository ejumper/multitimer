# P2.1 — Adapters + app wiring

**Goal:** Connect pure engine to the real desktop: system clock, drift store on disk (XDG), KDE/freedesktop notifications (click → focus app), mp3 sound player. App boots to board #1's timer, definitions loaded, run state always fresh (notStarted).

**Prereqs:** P1.x green, P0.2 green (shell exists).

**Read-first:** CONVENTIONS §2; P1.1 §2–§4 (interfaces to implement).

## Tasks

1. **Adapters in `apps/planner/lib/adapters/`:**
   - `SystemClock` → `Clock`.
   - `DriftStore(path)` → `Store` (+ `EventSink` impl writing the change log). DB at `$XDG_DATA_HOME/planner/planner.db` (default `~/.local/share/planner/`). Use `path_provider`.
   - `KdeNotifier` → `Notifier` interface: freedesktop notification via `local_notifier` (or `flutter_local_notifications` — executor picks; must support body + click callback on Linux/KDE). Click → focus Planner window.
   - `Mp3Player` → `SoundPlayer`: `just_audio` (or `audioplayers`); play-to-completion; overlapping alerts queue (next starts after previous; keep simple).
2. **Sounds directory:** `$XDG_DATA_HOME/planner/sounds/` — create if missing; README documents "drop .mp3 files here". Rescan-on-demand API for P4.3/P5.1.
3. **App state:** `AppController` (ChangeNotifier or simple stream) owning: board #1 + its timer (auto-create both on first run with empty interval list), a `TimerSession`, ticker driving `snapshot(now)` → UI rebuild (1 Hz is enough while running; snap to anchor-derived values). Forwards user intents → session. **Run state is deliberately never persisted:** every launch = notStarted over persisted definitions.
4. **Smoke path:** a temporary debug screen with Start/Pause/Skip buttons + snapshot text rendering (replaced by P3.1) to prove wiring end-to-end.

## Required tests

- Widget/integration: boot creates board+timer; reload keeps definitions, run state fresh.
- Adapter seams unit-tested with fakes (controller logic: intents → session calls, snapshot → state).
- Manual smoke on desktop: notification appears (via debug trigger), sound plays from sounds dir.

## Definition of Done

`flutter test` + `dart test` green; manual smoke documented in report; committed.

**Out of scope:** real board UI (P3.x), editors (P4.x), alert firing pipeline (P5.1).
