# P4.1 — Timer editor: shell, chips, toolbar basics, undo

**Goal:** The timer editor screen (right-click from board): working-copy semantics (✕ revert / Done save), color + label rows, interval chip list with nested group brackets, and toolbar basics: add, duplicate, delete, drag-reorder, snapshot undo. Grouping interactions are P4.2.

**Prereqs:** P3.2 green.

**Read-first:** UI-REFERENCE items 5 (editor layout), 9–10 (chips/brackets/nesting) + view the images: ../../../../multitimer-spec/REFERENCE-IMAGES/IMG_6212.PNG, ../../../../multitimer-spec/REFERENCE-IMAGES/IMG_6229.PNG, ../../../../multitimer-spec/REFERENCE-IMAGES/IMG_6230.PNG; P1.1 tree ops (duplicate-below-last-selected + non-sequential rule); v1/OUTLINE.md D12.

## Tasks

1. **Working copy:** editor operates on an in-memory copy; ✕ discards, Done commits via tree ops (each as a change-log event). Closing the app mid-edit = discard (no partial saves).
2. **Header:** ✕ (close) · title "Interval timer" · Done. 
3. **Color row:** the 6 hardcoded accent swatches (D11); selected shows ring. Timer color drives dial ring + accents on board.
4. **Label row:** "Add label" placeholder → timer name.
5. **Chips list:** each interval = chip card (color accent border, label, duration right-aligned, subtitle = end-alert sound name or none); groups = left bracket column w/ repeat count, chips indented inside; nesting = stacked bracket columns (mirror UI-REFERENCE 9–10 exactly). Selection circles far-left; multi-select supported.
6. **Toolbar:** `+` (opens interval editor — P4.3; stub route for now), duplicate (below last selected; non-sequential multi-selection inserts selection order at that point — P1.1 op), delete (selected chips AND selected groups), drag-reorder (chip or group; dropping inside vs outside a group moves membership), **undo icon** (replaces MultiTimer's legacy edit-mode): snapshot-stack undo, last ~50 mutations, per working-copy session.
7. Empty state: "no intervals" hint with add affordance.

## Required tests (widget + engine-integration)

- ✕ reverts all edits; Done persists (reload shows them).
- Duplicate rules (sequential + non-sequential cases from P1.1 tests, now via UI).
- Delete chip/group; reorder across group boundaries.
- Undo walks back mutations (grouped: one toolbar action = one undo step).
- Bracket rendering: nesting depths 1–3, repeat counts displayed.

## Definition of Done

`flutter test` + `dart test` green; visual check; committed.

**Out of scope:** group creation/ungroup/repeat modal (P4.2), interval editor contents (P4.3).
