# P4.3 — Interval editor + alert selector

**Goal:** The per-interval editor (add via `+`, edit via chip tap) and the alert selector screen. Completes all v1 editors.

**Prereqs:** P4.1 green (P4.2 parallelizable); P2.1 sounds-dir rescan API.

**Read-first:** UI-REFERENCE items 6 + 11 (interval editor layout, alert selector — we deviate: text boxes instead of keypad, no Start Alert/Note rows) + view the images: ../../../../multitimer-spec/REFERENCE-IMAGES/IMG_6222.PNG, "../../../../multitimer-spec/REFERENCE-IMAGES/Screenshot 2026-10-27 at 10.24.32 PM.png"; D12 (duration always-on, single auto-finish toggle).

## Tasks

1. **Screen layout** (mirror item 6 structure, v1 subset): ‹ back circle + "Interval" title (edits live — no Done); color row (6 swatches); label field; **auto-finish toggle** (the ONLY property toggle; off = manually complete); duration setter; End Alert row → selector.
2. **Duration setter:** three 2-digit boxes `hr min sec`, all start `00`. On blur or Enter, normalize overflow up: `00:10:90 → 00:11:30`. Zero total = "unset". Live-format hint showing parsed duration (`7m 30s`).
3. **Back (‹) commit rule:** edits apply; a NEW interval is added only if name non-empty OR duration > 0; otherwise back = cancel. (Editing an existing interval keeps it valid the same way — an existing interval can't be emptied below that rule; enforce on back.)
4. **Alert selector:** full-screen list of `.mp3` files from the sounds dir (rescan on open; empty dir → explanatory empty state pointing at the path). Each row: filename (minus extension), play-preview ▶ (plays via SoundPlayer), selected checkmark. Default selection = first alphabetical. "No alert" option at top. Selection persists as filename string. Preview auto-stops on selection/screen exit.
5. Chip subtitle in P4.1 list shows chosen alert name (or blank) — already specced there; wire it here if not already live.

## Required tests (widget + unit)

- Carry normalization: table of inputs → outputs (incl. 90s→+1m30, 75m→+1h15, 99h cap? no cap, boxes accept up to 2 digits each).
- Commit rule: name-only, duration-only, both, neither (add/skip cases); existing-interval enforcement.
- Alert selector: alphabetical order, default selection, preview invoked, "No alert", persistence round-trip.
- Selector empty-state copy.

## Definition of Done

`flutter test` green; user visual pass over both editors; committed.

**Out of scope:** alert FIRING at runtime (P5.1), Start Alert, Note, icons.
