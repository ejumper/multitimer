# P1.2 — Flatten: nested definitions → interval instances

**Goal:** The pure compiler from a timer's nested definition tree to the flat, ordered list of interval **instances** that execution consumes. Repeat N = **total passes**. Nesting uncapped. Single-interval groups = repeat-one-thing.

**Prereqs:** P1.1 green.

**Read-first:** CONVENTIONS §1; UI-REFERENCE items 5, 8–10 (group brackets, repeat stepper, nesting visuals — these define the data being modeled); FINAL-APP-OUTLINE.md §1 (property model).

## Tasks

1. `flatten(timer) -> List<IntervalInstance>` where `IntervalInstance {ordinal, defId, name, color, durationSeconds, autoFinish, endAlertSoundFile?}` — values snapshotted from defs at flatten time.
2. Semantics: group with repeatCount N plays its children N times total; groups nest arbitrarily; ungrouped intervals play once; empty timer → empty list.
3. `totalPlanned(instances) -> Duration` (sum). Empty → zero.
4. Deterministic and side-effect free; document complexity (linear in output size).
